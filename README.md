# Texas Badlands DayZ website

Responsive static website for Texas Badlands DayZ. Hosted on Vercel with GitHub.

## Before publishing

1. Open `index.html` and set `LINKS.discord`, `LINKS.facebook`, and `LINKS.kofi` near the bottom to the official HTTPS addresses.
2. Confirm all server information, feature descriptions, and rules before sharing publicly. Rules currently contain sample community guidelines, not official server policy.
3. The site is static and does not show real-time server status or player counts. No server IP has been invented.

## Publish

1. Create a new GitHub repository `texas-badlands` (not any of your existing repos).
2. Upload `index.html`, `README.md`, and the complete `assets` folder to that repository's root.
3. In Vercel, choose **Add New → Project → Import Git Repository** and select `texas-badlands`.
4. Set framework to **Other**, root directory to repository root, and deploy. No build command is necessary.

## Files

- `index.html` — complete responsive website.
- `assets/logo.png` — profile emblem.
- `assets/cover.png` — Texas Badlands cover art.
